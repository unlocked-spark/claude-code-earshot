# claude-code-a11y

Accessibility mod for Claude Code aimed at blind developers. It builds on the built-in screen reader mode and adds what the mode lacks: audible turn boundaries, earcons for tool events, a usable question dialog, filtered tool narration, speech on Windows, and automatic enabling of the mode when a screen reader is running.

Stage: research and product requirements, no code yet.

- `docs/prd.md`: product requirements, scope, milestones.
- `docs/research/rozpoznanie-2026-10-09.md` (Polish): what Claude Code offers today, open issues from blind users, what the mod API allows, existing projects, recommendation.
